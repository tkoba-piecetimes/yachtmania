大学ヨット部は470級・スナイプ級といった競技用ディンギーの購入・維持費に加え、水域予選から全日本学生ヨット選手権大会に至るまでの遠征費・合宿費もかさむ部活動です。部費やOB・OGからの寄付、企業協賛だけでは資金が足りないとき、選択肢のひとつになるのがクラウドファンディングです。この記事では、実際にクラウドファンディングに挑戦した大学ヨット部の例と、大学経由で行う場合の手続き・期間の目安、手数料、募集方式の違いを整理します。

結論として、クラウドファンディングは大学ヨット部にとって資金調達の選択肢になります。ただし、大学経由で行う場合は申請から入金まで数か月かかる場合があるため、早めの確認が欠かせません。

## ヨット部で資金が足りなくなりやすい理由

ヨット部の資金面の負担について、取材記事では次のような声が紹介されています。

- 国立大学のヨット部の取材では、セイル1式が約100万円、艇本体が約400万円と用具費が高額で、資金面が最大の課題とされています（[取材記事](https://media.tunakare.jp/university-students/5452242083/)）。
- 別のヨット部の取材では、艇6隻の往復輸送費だけで約30万円かかると語られています（[取材記事](https://media.tunakare.jp/university-students/6722788008/)）。
- 公立大学のヨット部の取材では、スポンサー営業で100社に連絡し、話を聞いてもらえるのは1社程度という状況が紹介されています（[取材記事](https://media.tunakare.jp/university-students/2026062601/)）。

企業協賛だけで必要な額をそろえるのが難しい場合に、支援者から直接資金を募るクラウドファンディングを検討する部もあります。支援を募る過程で部の活動内容や目標を言語化して発信すること自体が、OB・OGや保護者、地域の企業に部の存在を知ってもらう機会にもなります。

## 大学ヨット部がクラウドファンディングに挑戦した5つの例

各プロジェクトのページに掲載されている内容をもとに、5大学の例を表にまとめました。

| 大学 | プラットフォーム | 目的 |
| --- | --- | --- |
| 東京農工大学ヨット部 | READYFOR | 創部史上初の全日本インカレ出場に向けた遠征費などの支援（[大学ページ](https://yachtmania.jp/universities/tokyo-noko/index.html)） |
| 中央大学体育会ヨット部 | CAMPFIRE | 全日本インカレ出場と上位入賞を目指す活動資金（[大学ページ](https://yachtmania.jp/universities/chuo/index.html)） |
| 名城大学ヨット部 | READYFOR | 25年ぶりとなる世界選手権出場のための資金 |
| 徳島大学ヨット部 | Otsucle（大学クラウドファンディングサイト） | 全国10位を目標とした活動資金 |
| 金沢大学体育会ヨット部 | ブヒカツ | 艇の備品購入・修理や遠征費・合宿費用 |

中央大学のプロジェクトでは、艇や部品を新品ではなく中古で購入する、自分たちで修理する、遠征中の自炊で食費を抑えるといった日頃の工夫も紹介されています。水域や大学によって使用艇種や目標とする大会は異なりますが（[水域一覧のページ](https://yachtmania.jp/regions/index.html)）、艇という高額な備品を扱う部活動ならではの資金課題への向き合い方として、クラウドファンディングが使われている例があります。

他競技の参考として、立教大学ボート部のOB・OGへの取材記事では、コロナ禍で部の存続が危うくなった際に抵抗感を乗り越えてクラウドファンディングに挑戦し、目標の3倍を集めたことが紹介されています（[取材記事](https://media.tunakare.jp/ogob-interview/5750957436/)）。

## 大学経由で行う場合の手続きと期間

大学によっては、学生団体のクラウドファンディングを大学の寄附金募集として扱い、学内での申請・審査を求める場合があります。公開されている2大学の案内から、期間の目安を紹介します。

| 大学 | 手続きの流れ・期間の目安 |
| --- | --- |
| 神戸大学（課外活動団体向け） | 申請書提出 → 学生委員協議会で審議 → 学長が実施承認 → READYFORと掲載内容を調整 → 実施（2か月程度）→ 目標達成した成立月の翌々月に大学へ入金 → 予算配分。申請から予算配分まで約6か月が目安（[神戸大学の案内](https://www.kobe-u.ac.jp/documents/campuslife/life/club/cloudf_period_c.pdf)） |
| 東京科学大学（2025年5月時点） | 学内審査 約30日、READYFOR審査・相談 約45日、募集期間 10〜59日、募集完了後に大学へ入金されるまで 40〜70日（[東京科学大学の案内](https://www.titech.ac.jp/student-support/pdf/new-cf-flowchart-2025may.pdf)） |

目標とする大会や遠征の日程から逆算すると、準備を始める時期は早めになります。手続きは大学ごとに異なるため、所属大学の窓口で確認してください。

## 手数料と募集方式（All-or-Nothing／All-in）

### 手数料

東京科学大学の学生向けの案内では、READYFORの手数料は3つのプランから選ぶ形で、ベーシックプラン13.2%、サポートプラン18.7%、コンサルティングプラン19.8%と示されています。学生クラウドファンディングではREADYFORへの手数料のみが発生すると説明されています（[東京科学大学の案内](https://www.titech.ac.jp/student-support/pdf/new-cf-flowchart-2025may.pdf)）。これは同大学の例であり、プラットフォームや大学、時期によって条件は変わる場合があります。CAMPFIREなど他のサービスの手数料は、各サービスの公式ページで確認してください。

### 募集方式

READYFORの解説では、募集方式は次の2種類に分けて説明されています（[READYFORの解説](https://readyfor.jp/sapuris/30)）。

| 方式 | 内容 |
| --- | --- |
| All-or-Nothing | 目標金額に届かなければプロジェクトは不成立となり、集まった支援金は支援者に返金される |
| All-in | 目標未達でも集まった支援金を受け取れる。利用にはREADYFORの承認が必要 |

どちらを選ぶかで、目標額の考え方が変わります。目標に届かなかった場合に資金が入らない可能性があるのか、事業を完遂する責任が残るのかを、実施前に確認しておくと安心です。

## 大学基金・企業協賛との違いと組み合わせ方

クラウドファンディングは支援者から直接資金を募る仕組みですが、大学によっては別の仕組みで部を支援する制度も設けられています。たとえば京都大学には「ヨット部活動支援基金」があり、大学の基金制度を通じて部の活動を支援する仕組みが用意されています。こうした大学基金や、企業からのスポンサー・協賛は継続的な支援を受けやすい一方、クラウドファンディングは「インカレ初出場」「創部○周年」といった具体的な目標やストーリーを掲げやすく、単発の大きな支出に対して短期間で支援を募りやすいという特徴があります。大学基金やOB会による公式な支援のしくみは、[大学ヨット部はどんな公式支援を受けられる？ 大学基金・OB会による資金支援のしくみ](https://yachtmania.jp/articles/yacht-bu-daigaku-kikin-obkai-shien/index.html)<!-- index-lane-link -->で整理しています。

あわせて、次の記事も資金計画の参考になります。

- 企業からの支援を集める方法: [ヨット部の協賛・スポンサーの集め方](https://yachtmania.jp/articles/yacht-bu-kyousan-sponsor-atsumekata/index.html)
- 遠征・合宿の費用の目安: [ヨット部の遠征・合宿費用](https://yachtmania.jp/articles/yacht-bu-ensei-gasshuku-hiyou/index.html)
- 寄付金控除のしくみ: [ヨット部への寄付と寄付金控除](https://yachtmania.jp/articles/yacht-bu-kikin-kifukin-koujo/index.html)
- 大学の課外活動助成金: [大学の課外活動助成金](https://yachtmania.jp/articles/yacht-bu-daigaku-kagai-katsudo-jyoseikin/index.html)

## クラウドファンディングに挑戦する際に意識したいポイント

実際にクラウドファンディングを始める大学ヨット部の例を見ると、次のような点が意識されています。

| ポイント | 内容 |
| --- | --- |
| 目的の明確化 | 「インカレ初出場」「艇の買い替え」など、何のための資金かを具体的に示す |
| 学内手続きの確認 | 大学経由で行うかどうか、申請から入金までの期間はどれくらいかを、所属大学の窓口で早めに確認する |
| 部の歩みの発信 | 部員数の推移や創部からの歴史など、支援したくなる背景を伝える |
| 節約努力の可視化 | 中古艇・パーツの活用や自炊などの自助努力もあわせて発信する |
| 返礼品と活動報告 | 支援者への返礼品の準備と、終了後の活動報告までを計画に含める |
| SNSでの継続発信 | プロジェクト期間中も練習や大会の様子を発信し、支援の輪を広げる |

こうした発信は、クラウドファンディングの支援者探しだけでなく、[大学からヨット部・セーリング部を選ぶ](https://yachtmania.jp/articles/daigaku-yacht-bu-erabikata-checklist/index.html)高校生や、部の資金面の実情を知りたい保護者・OB・OGにとっても有益な情報になります。

体育会学生を支援するプラットフォーム「ツナカレ」でも、[部活動の情報を掲載できるページ](https://lp.tunakare.jp/s01/)を用意しています。支援を募る前に、部の活動を知ってもらう入り口として活用できます。

## まとめ

大学ヨット部にとってクラウドファンディングは、部費やOB・OG支援、企業協賛と並ぶ資金調達の選択肢のひとつです。大学経由で行う場合は申請から入金まで数か月かかる場合があるため、手続きと期間は所属大学の窓口で確認し、手数料や募集方式の違いも踏まえて計画を立ててください。各大学ヨット部の活動拠点や使用艇種は水域によって異なるため、興味のある方は[ヨットマニアの水域一覧ページ](https://yachtmania.jp/regions/index.html)から、各部の活動状況もあわせて確認してみてください。
