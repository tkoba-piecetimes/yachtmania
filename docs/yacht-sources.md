# データソース調査記録（大学ヨット）

大学ヨットは全国9水域（北海道・東北・関東・中部・近畿北陸・関西・中国・四国・九州）の
学生連盟が大会を運営している。試合が「対戦→スコア」形式のリーグ戦ではなく、水域予選→
全国大会という選手権（レガッタ）形式で、成績はほぼPDF配布のため、ラグビーマニア等の
「試合結果・順位表」型のサイト構造はそのまま流用できない。そのためMVPは
「大学ディレクトリ＋大会カレンダー＋成績PDFリンク集」に絞った（PDFの中身は解析しない）。

## 関東学生ヨット連盟 (kantogakuren.org)

- 加盟大学: `https://kantogakuren.org/members?hsLang=ja-jp`
- HubSpot CMS（`PreRenderedContentResolver`）でサーバーサイドレンダリング済みのHTMLが
  返るため、素のurllibで取得できる（JS実行不要）
- 加盟大学は`<article class="hs-elevate-card ...">`カード36枚。構造:
  `<h3 class="...card-container__title">大学名(日本語)</h3>` →
  `<div class="...card-container__body"><p>英語名<br>出場クラス<br>練習拠点</p></div>` →
  `<a class="...card-container__button" href="公式サイトURL">公式HPへ</a>`
- **重要**: `?hsLang=ja-jp`付きURLは307で`/members`にリダイレクトされる
  （`-L`相当が必要。urllibはデフォルトで追従する）
- 実装: `pipeline/fetch_kanto.py`

## 近畿北陸学生ヨット連盟 (kinhokugakuren.com)

- 大会日程: `https://www.kinhokugakuren.com/スケジュール`（Wixサイト）
- 日程は`<h3>日付</h3>`直後の`<p>大会名</p>`という repeater 構造（14件、2月〜12月）。
  年度の記載がないため、日付は連盟の表記をそのまま文字列として掲載し、
  西暦へのマッピングはしていない
- 加盟大学（10校）はスケジュールページを含む全ページ共通のフッターに、大学名リンクの
  一覧として埋め込まれている（`id="SITE_FOOTER"`以降）。「○○大学...ヨット部」という
  リンクテキストから大学名を抽出
- 実装: `pipeline/fetch_kinki_hokuriku.py`

## 全日本学生ヨット連盟 (zennihon201809.com)

- 水域大会成績: `https://www.zennihon201809.com/大会成績/水域大会成績/{year}年度/`
  （インデックスページ`/大会成績/水域大会成績/`から年度別サブページを動的に列挙。
  2026-08-14時点では2025年度のみ存在）
- Jimdoサイト。水域見出し（例:「北海道水域」）ごとに470級・スナイプ級のPDFダウンロード
  リンクが並ぶhgridテーブル構造。見出しの出現位置とPDFリンクの出現位置を突き合わせて
  「どのPDFがどの水域か」を判定している（`fetch_zennihon.py: parse_result_pdfs`）
- ダウンロードリンクは`/app/download/{数値ID}/{URLエンコード済みファイル名}.pdf?t=...`。
  この数値IDをPDFの一意キーとして使い、日次クロールで「初検知日（first_detected_at）」を
  維持しながらマージしている（`fetch_all.py: merge_result_pdfs`）
- 大会日程ページ（`/大会日程/`）はPDF2件（2024年度・2019年度の水域別スケジュール表）への
  リンクのみで、日程そのものはHTML化されていない。ナビゲーションから「全日本学生ヨット
  選手権」「同 個人選手権」「同 女子選手権」の最新の大会情報ページ（第89回・2025年度・
  第34回など）へのリンクだけ抽出し、カレンダーに「日程は大会情報ページを参照」として掲載
- **重要**: サイト内リンクの一部（成績PDFへのリンク等）はhref属性が最初からURLエンコード
  済みだが、ナビゲーションリンクは生のUTF-8文字列（未エンコード）。urllibでの取得時に
  `urllib.parse.quote`で毎回エンコードしてから送信する必要がある
  （`common.py: fetch`が自動対応）
- **重要**: PDFファイル名の一部がUnicode正規化形式NFD（濁点・半濁点が分解された状態）で
  配信されており、`"スナイプ"`のような文字列比較がNFC表記と一致しないことがある。
  `common.py: nfc()`でNFC正規化してから比較・保存している
  （中国水域のスナイプ級PDFで実際に発生した不具合）
- 実装: `pipeline/fetch_zennihon.py`

## 見送った水域・データ（2026-08-14時点の調査）

- **関西学生ヨット連盟**（Google Sites: `sites.google.com/view/kansaigakuren-sailing`）:
  アクセスするとGoogleログイン画面へ302リダイレクトされ、非ログイン状態では内容を
  取得できない。関西水域の大学ディレクトリ・独自カレンダーは「準備中」表示とし、
  大会成績PDFのみ全日本学連の水域大会成績ページ経由で掲載している
- **全日本学連の加盟校名簿**（`/加盟校/`ページ）: 年度別にxlsx/PDFのダウンロードリンクの
  みで、HTML化された一覧が存在しない。関東・近畿北陸以外の水域（北海道・東北・中部・
  中国・四国・九州）の大学ディレクトリが「準備中」なのはこのため
- **北海道・東北・中部・中国・四国・九州の独自サイト**: 各連盟の公式サイトへのリンクは
  全日本学連サイトのフッター等から拾えたものだけ`pipeline/regions.py`に登録した
  （東北・中国・四国・九州は該当リンクが見つからず未登録）。これらのサイトを個別に
  巡回した調査は今回のスコープ外
