# KW在庫と編集戦略（ヨットマニア）

策定日: 2026-09-10（木場さん決定「全オウンドメディア月100本体制。部活メディアは上位クエリを狙いつつ、部員が見に来る場所という地位を確立する」に基づく）

対象: 大学ヨット（セーリング）情報メディア「ヨットマニア」（SITE_BASE: https://yachtmania.jp/ 、現状公開URL: https://tkoba-piecetimes.github.io/yachtmania/ ）

前提: MVPスコープは「水域別の加盟大学ディレクトリ（関東36校・近畿北陸10校のみ。他7水域は準備中）＋大会カレンダー＋成績PDFリンク集」。既存記事は「艇種ガイド」「部活選び」「初心者ガイド」「ポジションガイド」「大会ガイド」「水域まとめ（関東2025のみ）」「新着成績（自動）」「大学別成績（自動、関東のみ13校）」「キャリア」「部活運営」「就活」をカバー済み（詳細は`content/articles/`一覧参照）。本ドキュメントはその上に積み増す新規KWの在庫。記事は3,000字以上、H2から開始、frontmatterは`title`/`description`/`category`/`date`/`cta`の5項目のみ（`bukatsu-seo-article` SKILL.md準拠）。

**対応地区の制約に注意**: 大学ディレクトリは関東・近畿北陸のみ対応。北海道・東北・中部・関西・中国・四国・九州の大学ディレクトリは「準備中」（`docs/yacht-sources.md`参照）。記事内で「全国の大学ヨット部」をあたかも網羅しているかのように書かず、対応地区外は「大会成績PDFのみ掲載」である旨を明記する。

一次データページのURL構造（内部リンク先）: `/regions/`（水域一覧）・`/regions/<code>/`（水域ページ）・`/universities/<slug>/`（大学ページ）・`/calendar/`（大会カレンダー）・`/results/`（成績PDFリンク一覧）・`/results/<id>/`（成績ページ）・`/articles/<slug>/`

## 1. 戦略メモ：部員が検索する10の場面

1. 高校生・保護者が「大学ヨット部 強豪」「大学から始めても遅くないか」を検索する（既存記事で一部カバー）

**3層で面を作る方針**:
- **H（上位クエリ）**: 大学名×強豪、日本代表輩出、大会名（全日本学生ヨット選手権）、艇種（470/スナイプ）、道具（艇・セール）の値段、初心者向け、就職先。既存の水域・大学ディレクトリ、成績PDFデータと組み合わせて差別化する。更新型は年1回リライト
- **P（部員向け定番）**: セーリング技術（タッキング等）、怪我・体調管理、栄養、道具の手入れ・費用、用語、新歓/引退、マネージャー/学生コーチなど、部員の日常的な悩みに答えるロングテール本体
- **K（企画）**: 自サイトが持つ一次データ（水域別大学ディレクトリ、成績PDF集計）を横断集計したランキング・まとめ企画。既存の`result-*`（新着成績、自動）・`univ-results-*`（大学別成績、自動）と同じ内容を並べ直すだけの記事は作らない

## 5. 運用メモ

- **月ごとの制作配分の目安**（このサイト単体）: 月4〜6本を目安に、H:P:K = 2:3:1 程度の比率で配分。データ更新（水域拡大・新着成績PDF検知）と並走させる
- **1記事1意図**: H1/H2/H16、H7/H8（見送り）、H9/H10、H12/H13のように同義・近接クエリは統合または「見送り」判断を明記し、1本のKWクラスタに1記事とする
- **90日表示ゼロは統合・削除**: GA4で公開90日後に表示0のロングテール記事は近接テーマへ統合するか`content/articles/`から削除する
- **更新型記事は年1回リライト**: H1/H2（強豪校ランキング）、H4（全国大会日程まとめ）、H3/H16/K7（代表輩出）は当年のシーズン終了後（10〜11月頃）に更新
- **対応地区外の扱い**: K1・K8など水域横断の企画記事は、関東・近畿北陸以外を「大学ディレクトリは準備中、大会成績PDFのみ掲載」と明記し、対応済みであるかのような誤解を与えない
