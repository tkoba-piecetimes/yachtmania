# SERP分析: ヨット部 ウェットスーツ ドライスーツ 選び方

調査日: 2026-11-23 / 類型: 部員向け定番（P・道具）・進路系/観戦系/就活系のいずれでもない（cta: sponsor）
補足: keyword-inventory.mdのP1〜P27・H系は既存記事で消化済みのため、在庫外の道具系ロングテールとして新規選定（既存の低体温症記事は「寒さと落水対策」、本記事は「選び方・厚さ・手入れ・重量規則」で意図を分離）。

## 上位の顔ぶれ
- ネオネットマリン（セーリング用品店）ドライスーツ基礎知識 / 楽天ショップのドライスーツ解説
- オニール公式 ヨット用スーツ紹介（モビーディック）
- 個人ブログ（best-wind、yamasan4 など）の冬の服装レポート
- アクティビティポータル「高校生のヨット部の大会で使用するドライスーツの選び方と規定」
- 以降はダイビング・サーフィン向け（PADI、CITYWAVE TOKYO、owd.jp、マハロ大阪など）

## 共通点（検索意図の正解）
1. ウェットは入った水を温める／ドライは水を入れずインナーで調整、という仕組みの違い
2. 水温が低いほどドライ、というおおまかな切り替え目安と、厚さ（2/3/5mm）
3. サイズ・フィット・ジッパー位置などの選び方

## 欠けている要素（差別化点）
1. セーリング専用で、ウェット・ドライを横断して「形（ロングジョン等）・ポジション別・厚さ・手入れ・費用」を一通り扱う記事がない（ダイビング/サーフィン向けが大半）
2. 大会ルール（RRS 2025-2028 規則50.1の衣類重量・体重増加目的の禁止）と装備選びを結びつけた解説がない
3. 他競技の水温目安を「ヨットにそのまま当てはまらない」と明示して使う編集姿勢、および大学ヨット部の水域・大会カレンダー（一次データ）への導線

## 使用した一次・準一次情報
- ネオネットマリン ドライスーツ基礎知識（種類・ジッパー・シール・インナー・手入れ・修理）
- O'NEILL ヨット用スーツ（形・厚さ・ポジション別・フィット）。水温別の数値記載なし
- CITYWAVE TOKYO 水温別早見表（サーフィン向け・関東基準）。ヨット向けではない旨を本文に明記
- ZERO1 SURF ウェットスーツの洗い方・保管
- アクティビティポータル（高校ヨット部・中古購入と大会前確認。厚さの数値なし）
- World Sailing RRS 2025-2028 規則50.1（体重増加目的の着用禁止・衣類装備8kg上限）。旧版の規則43から番号が変わっている点に注意。JSAF規則ページへリンク
- 気象庁 海面水温（月概況）

## 注意メモ
- docs/primary-sources/ はyachtmaniaに存在しないため、一次情報バンクの項目は使用していない（一般論は出典付きで記述）

- 規則50.1の日本語条文は未確認（英語版テキストで確認）。本文でJSAFページと大会公示での確認を促している
