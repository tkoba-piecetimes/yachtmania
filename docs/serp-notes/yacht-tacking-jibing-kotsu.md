# SERP分析メモ: タッキング ジャイビング コツ（yacht-tacking-jibing-kotsu）

調査日: 2026-09-18

## 確認クエリ
- 「タッキング コツ ヨット 初心者」
- 「ジャイビング 練習方法 ヨット セーリング」
- 「ヨット タッキング やり方 手順」

## 上位の顔ぶれ
ヤマハ発動機（マリン製品サイト）、モーターボート用語集（kazi.co.jp）、公益財団法人ブルーシー・アンド・グリーンランド財団（B&G財団）のヨット講座、舵オンライン（kazi-online.com）、個人ブログ・YouTube動画が中心。大学ヨット部・体育会系メディアは上位に出てこない。

## 共通点（検索意図の正解）
1. タッキングは「クローズホールドからクローズホールドへの風上方向転換」、ジャイビングは「ランニングからの風下方向転換」という定義を起点に、ティラー操作→ブーム移動→新舷でのトリムという3〜5段階の手順で説明する構成が共通している。
2. ヤマハ・B&G財団の記事は「クローズホールド」「ラフィング」「ティラー」「ベアアウェイ」等の専門用語を解説なしに使っており、ある程度の予備知識がある読者を前提にしている。
3. 「風の弱い日から練習し慣れてから強風を経験する」「艇速を落とさない」「頭を低くしてブームを避ける」といった安全面の注意喚起は共通して触れられているが、練習の場（マルチハル・クルージング艇・ディンギーなど艇種はまちまち）や、2人乗り艇でのスキッパー・クルーの役割分担についての言及はほぼない。

## 差別化点（上位に欠けている要素）
- 大学ヨット部が主に使う470級・スナイプ級（スキッパー・クルーの2人乗りダブルハンド艇）を前提にした解説がない。上位はクルージングヨットやマルチハル（トライマラン）を例にしており、大学の新入部員が自分の艇に当てはめて読みにくい。
- 専門用語（クローズホールド・ラフィング・ベアアウェイ等）の解説を挟まずに手順を説明する記事が多く、初心者にはハードルが高い。
- タッキング・ジャイビングを「スキッパーとクルーの連携」という観点から整理した記事がない。
- 自サイトの一次記事（艇種の違い・ポジションの違い・基礎練習の全体像）と接続してあわせて読む導線を作れる競合はいない。

## 採用方針
大学ヨット部の新入部員・初心者クルー/スキッパーを対象に絞り、470級・スナイプ級とスキッパー・クルーの役割分担を前提にタッキング・ジャイビングの手順とよくあるつまずきを整理する。内部リンクは `daigaku-yacht-470-snipe-chigai`（艇種の違い）・`daigaku-yacht-bu-skipper-crew-chigai`（ポジションの違い）・`yacht-bu-renshu-menu-kiso`（基礎練習の全体像）へ設置する。
