## 上位の型（確認できた範囲）
- 型はすべて「解説（手順＋注意点）」。自記事と型は一致している（検索意図のずれはない）。
- ヤマハ発動機: 見出し「タッキングとは／ジャイビングとは／ディンギーヨットを安全に楽しむために」。手順は3段階の番号付き。舵柄とシートの持ち手を替える、シートを緩めない、風下に落としすぎない、ジャイビングは微風で練習、シートを踏まない・整理する、セールの展開が悪いと沈の原因、まで書く。
- B&G財団 Lesson6（タッキング）: 手順5段階＋実践のコツ（周囲確認、頭の中でシミュレーション、ブローや波で減速したときは避ける、一定の風で艇速が保たれているときに始める）＋「失速（ストール）」の節（バウの回転不足、タッキング中にメインシートを緩めるとストール）。風見リボンが正面から流れたら風上を向いた目安。
- B&G財団 Lesson8（ジャイビング）: 手順5段階。慣れたらシートを手でつかんでセールを反対舷へ送り出すとブームの勢いを抑えられる、練習は微風から。
- 英語上位: 始める前の声かけ（Ready about / 役割の割り振り）、艇速があるときに入る、ジブを放すタイミング、舵を持ち替える手を急がない、ロールタック（小型ディンギーの体重移動で回す技術）。

## 自記事との差（リライトで埋める点）
1. 手順が文章のみで、番号付きの段取りになっていない（上位は3〜5段階のリスト）。
2. 「コツ」の具体が薄い。上位が書いている「メインシートを緩めると失速」「ブロー・波で減速したときは避ける」「風見リボンの目安」「回り終えて落としすぎない」「シートを手で送ってブームの勢いを抑える」「シートの整理」「持ち手の替え」が抜けている。
3. ジャイビングの手順にティラー操作（わずかに風上側へ引く）が書かれていない。
4. 冒頭が長く、コツの要点が先に出てこない。

## 差別化（維持する点）
