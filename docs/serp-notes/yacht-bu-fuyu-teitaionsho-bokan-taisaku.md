# SERP メモ: ヨット部 冬 低体温症 防寒（P・怪我体調／道具）2026-11-20

- 上位はダイビング向け（PADI・DIVE SSI）のウェット／ドライ解説と、海上保安庁・水難救済関連の生存時間資料が中心。検索意図の共通点は「水温で装備を選ぶ」「落水時は動かず体温を守る」「頭部・インナーで保温」。大学ヨット部の部員向けに冬季練習の防寒を扱う記事は見当たらず（香川大学ヨット部は冬季練習オフ、東工大は伴走艇での安全確保の紹介のみ）。
- 欠けている要素: ヨット特有の事情（風による体感温度低下、沈・落水の頻度、待機時間、陸上艤装中の冷え）、水温別の目安を出典付きで学生向けに整理したもの、部としての仕組み（入水時間の上限・保温の場所・伴走艇連携）。
- 差別化: 海上保安庁（第二管区「マリレ情報よろず屋」第5号 2012年12月、第九管区「海の安全情報」2023年11月号）の水温別の生存時間の目安を引用し、既存の沈・ライフジャケット・陸トレ記事と水域一覧・大会カレンダー・大学ページへつなぐ。ダイビング向け情報は「別競技の目安」と明記。
