# SERPメモ: ヨット部 出艇判断 強風 雷（2026-11-24）

狙いKW: ヨット部 出艇判断 強風 雷 / 類型: 部員向け定番（P）・安全
選定理由: keyword-inventory の P は既存記事で網羅済みのため、既存記事に近接しない安全系の空白テーマを選んだ（既存の天気図・風向判断・ライフジャケット・転覆起こし方記事とは「出艇するか中止するか」の判断手順で分離）。

1. 上位は一般ボート・釣り船の出航判断ガイド（風速8〜10m/sで見送り目安、11m/s以上中止等）と、大学ヨット部の安全対策ページ（滋賀医科大・東京科学大セーリング部・立教大）が中心。ヨットの統一数値基準を示す記事は見当たらず、各部は管理者指示と総合判断で運用している。
2. 雷は日本ボート協会の安全マニュアルが明確（雷鳴・稲妻が視認できれば新規出艇しない、収まって20分以上待つ）。気象庁も「雷の活動が止み20分以上経過してから移動」と説明。強風注意報の基準は地域差があり（海上15m/s等）、数値は予報区ごとに確認が必要。
3. 欠けている要素: 新入部員向けに「前日・当日朝・出艇前・出艇後」の判断を時系列で整理し、数値を決め打ちせず部で基準を作る手順（チェックリスト）まで落とした記事。自サイトの水域・カレンダーページとの接続もない。
