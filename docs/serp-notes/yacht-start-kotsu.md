## KW選定の経緯
- docs/keyword-inventory.md の部員向け定番（P1〜P27）は既存記事で全て着手済みだったため、同じ「セーリング技術」カテゴリで未着手のスタート技術（レーススタートの位置取り・加速）を選定。インベントリ外の追加KWとして扱う。
- 既存`yacht-race-rule-kiso`はスタート信号・OCSの規則面のみ。技術面（ライン確認・位置取り・加速・練習）は不在でカニバリしない。規則面は同記事へ内部リンクして重複を避ける。

## 共通点（検索意図の正解）
1. 有利端（ラインバイアス）の見つけ方と、端そのものは混むこと
2. 時間と距離の管理（ラインまでの所要時間を測る）
3. ゼロから全速への加速と、良いスタート＝クリアな風で全速

## 欠けている要素（差別化）
1. 日本語で大学ヨット部（470/スナイプの2人乗り）の部員に向けた整理
2. 規則（OCS・I旗等）と技術の接続、練習メニュー化
3. 一次データ（大会カレンダー・成績PDF）で成績表のOCS表記を見る導線
