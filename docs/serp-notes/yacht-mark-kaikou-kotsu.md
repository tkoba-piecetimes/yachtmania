## 共通点（検索意図の正解）
1. 回航の目的は「速く・きれいに（接触なし）・次のレグに向けた位置で出る」
2. 風上マークはレイライン手前の渋滞とポートタック艇に注意、風下マークは進入速度と出口（次の風上マークを見据える）
3. ベアアウェイ（スピン展開）かジャイブセットかは戦略と乗員の習熟度で決める
4. 役割分担と事前の取り決めが大切

## 欠けている要素（差別化点）
1. 大学ヨット部の新入部員向けに日本語で、風上マーク→風下マークの順に1本で整理した記事がない
2. 海外記事の多くはキールボートの文脈。大学ヨットの2人乗り（470級・スナイプ級）へ当てはめる際の注意（そのまま当てはまらない点）を明記する
3. 既存のルール基礎（規則18）・スタート・タッキング・ヒール・風向き記事への回遊導線と、練習メニュー化
